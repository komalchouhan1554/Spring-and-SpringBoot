# 🕵️ Hidden Form Fields

- 🔒 A **hidden form field** is a specific type of HTML form field used to store data on the client side (browser) while keeping the data **hidden from the user**.
- 🔄 It is used to pass data from one page to another, or from browser to server, **without displaying the data** to the user.

## ✍️ Syntax

```html
<input type="hidden" name="----" value="----" />
```

## 🎯 Uses of Hidden Form Field

1. 🍪 Session tracking mechanism
2. 📤 Passing data between pages
3. 🛡️ Security tokens
4. ⚙️ Storing user preferences
5. 🔗 URL redirection
6. ➕ etc.

## ⚠️ Note

> Hidden form fields are **not suitable** for storing sensitive and confidential information, since the data is visible in the page source code 👀 and can be manipulated by the user ✏️.
